# 猫狗熟自制多路线营养知识库

## 一、结论速览

熟自制没有一条“正确肉类比例”。按证据等级看，至少存在五条路线：

1. **临床营养学路线**：由兽医营养师依据NRC、AAFCO/FEDIAF需求，对每只动物、每种食材和每个生命阶段计算，允许从极低碳水到约50%熟碳水。
2. **BARF路线**：强调生物适宜性与部分植物性食物，经典生食结构为“80%动物＋20%植物”，熟制版本用钙粉替代熟骨。
3. **PMR/猎物模型路线**：尽量复刻整只猎物，通常无植物原料；犬可采70–80%肌肉肉、10–15%生可食骨、5%肝脏、5%其他内脏；猫可采84%肌肉肉、6%生骨、5%肝脏、5%其他内脏。
4. **高肉新鲜粮路线**：典型代表是《永远的爱犬》，其官方鸡肉全阶段犬食谱的动物原料约占76%，蔬菜约22%，鱼贝合计约10%。
5. **生食改良熟制路线**：保留高肉、内脏轮换和鱼贝/植物化学物理念，但全熟杀菌，再通过钙、碘、维生素E、牛磺酸等补平烹饪损失。

**五条路线不能混成一个模板。**临床营养学强调营养素核算，BARF强调结构比例，PMR强调整只猎物，永远的爱犬强调低加工、植物抗氧化物和动物多样性，熟制路线则额外关注病原体与热敏营养素。

因此，skill应把“原料百分比”和“营养素含量”分别存储：

- 原料百分比只用于采购、切配和复现食谱；
- 蛋白质、脂肪、碳水化合物热量百分比，以及钙、磷、牛磺酸、维生素A/D/E等营养素，才是判断完整性的依据；
- 原料比例看起来很“高肉”，不代表营养完整；反之，临床配方肉含量较低，只要营养素核算通过，也不等于不合格。

截至2026年9月26日，公开资料没有提供一套覆盖所有犬猫疾病、全部鱼种和所有食材批次的统一熟制比例。因此本文件中的区间应被视为配方起点，而非个体处方。

## 二、五条路线总览

| 路线 | 核心逻辑 | 动物原料典型范围 | 碳水角色 | 鱼的作用 | 适用边界 |
|---|---|---:|---|---|---|
| 小动物临床营养学 | 按营养需要核算 | 犬约40%–75%；猫约34%–75%，依配方而异 | 可从约0%到50%湿重 | 轮换蛋白或脂肪酸来源 | 需兽医营养师、配方软件与检验 |
| BARF | 生物适宜、生食为主 | 犬约70%–80%肉＋骨；植物约20% | 蔬菜/水果提供纤维和植物化学物 | 可轮换，不是默认主蛋白 | 原始模板为生食，熟制不能照搬骨比例 |
| PMR/猎物模型 | 复刻整只猎物 | 犬约80%–90%；猫约90%–95% | 通常不加入植物；可用皮毛/羽毛纤维 | 可小比例轮换 | 极缺植物成分不代表熟制后不需补剂 |
| 永远的爱犬 | 高动物原料、低加工、多样化 | 犬官方鸡肉食谱约76% | 蔬菜同时提供体积、纤维和植物化学物 | 鱼＋贝类共同补充脂肪酸与微量元素 | 理念书而非统一临床标准 |
| 生食改良熟制 | 在食品安全前提下保留高肉 | 通常犬55%–70%、猫65%–85% | 0%–15% | 单次5%–10%，长期鱼主粮≤30%–40% | 补充体系比原料百分比更重要 |

## 三、小动物临床营养学路线

### 3.1 它真正强调的是计算，而不是“肉占多少”

《小动物临床营养学》的熟自制原则不是固定肉量，而是把肉/鱼、蔬菜、脂肪和补充剂分别输入配方软件，汇总后与犬猫营养需要比较。其公开教学摘要建议：

- 肉或鱼切成适合动物体型的小块；
- 采用蒸或煮等方式，使中心温度达到70℃；
- 蔬菜通常至少提供维持能量需求的4%；食欲良好、能量需求低时可以提高到10%–15%；
- 菜籽油或大豆油可以承担一部分能量；
- 脂肪酸不足时可用动物脂肪补充；
- 汇总已有成分后，仍应加入至少含钙、6种微量元素和12种维生素的维生素—矿物质补充剂；
- 加入零食时，要从当日总能量中扣除。

因此，“熟自制必须低碳水”并非该路线的必然结论。它允许犬的部分能量由碳水化合物或脂肪提供，具体取决于犬的碳水耐受度、能量需求与食欲。

## 四、BARF路线

### 4.1 经典结构

BARF强调“生物适宜”，起源于生食体系，通常包含肌肉肉、生可食骨、内脏和少量植物性食物。典型犬结构为：

- 肌肉肉：70%–80%
- 生可食骨：10%–15%
- 肝脏：约5%
- 其他内脏：约5%
- 蔬菜/水果：约5%–10%

注意，这里的70%–80%往往是“肌肉肉＋肉骨”的合并口径；把生可食骨独立拆分后，纯肌肉肉比例会下降。

猫的经典BARF结构通常更偏动物来源：

- 肌肉肉：约84%
- 生可食骨：约6%
- 肝脏：约5%
- 其他内脏：约5%
- 植物：0%–5%，猫不是必须使用植物

### 4.2 熟制后的关键转换

BARF原始模板依赖生可食骨提供钙和磷，但熟骨坚硬、易碎，不应直接用于熟自制。熟制转换必须至少处理：

1. 取消熟骨，改用适合全价熟制配方的钙源；
2. 按总磷和可吸收钙倒推钙添加量，不机械套用“每500g加多少”；
3. 鱼、蛋、肝脏和油的比例仍按生食模板执行，不代表营养素已满足；
4. 硫胺素、牛磺酸、维生素E等需要单独检查；
5. 熟制能降低部分病原体风险，但不能替代食材追溯、交叉污染控制和兽医随访。

因此，skill调用BARF模板时应增加标签：

```yaml
barf:
  raw_base_applicable: true
  cooked_conversion_required: true
  cooked_bone_policy: "禁止直接使用熟骨"
  calcium_source: "由配方软件重新核算"
```

## 五、PMR/猎物模型路线

### 5.1 核心结构

PMR主张尽量喂整只猎物，或采用不同动物部位组成“拼凑猎物”。公开资料中的常见结构为：

- 肌肉肉：75%–80%
- 生可食骨：10%
- 肝脏：5%
- 其他分泌型内脏：5%
- 动物源不溶性纤维：0%–5%

猫更常见的PMR结构为：

- 肌肉肉：79%–84%
- 生可食骨：6%
- 肝脏：5%
- 其他分泌型内脏：5%
- 皮毛/羽毛纤维：0%–5%

“肌肉肉”通常是合并口径，可包含部分心脏等高营养肌肉组织。部分资料对猫允许生骨在6%–10%之间调整，但熟制版本不应机械沿用。

### 5.2 PMR与BARF的关键差异

| 项目 | PMR/猎物模型 | BARF |
|---|---|---|
| 植物原料 | 通常无 | 通常有蔬菜/水果 |
| 核心理念 | 复刻整只猎物 | 生物适宜＋部分植物 |
| 动物原料比例 | 更高 | 略低但仍有较高变体 |
| 多样性来源 | 多物种、全动物部位 | 多蛋白＋植物多样性 |
| 鱼 | 可小比例轮换 | 可小比例轮换 |
| 熟制风险 | 高肉＋单一内脏易造成隐性缺口 | 同样必须重新核算 |

PMR高比例不代表天然完整。若长期只用鸡胸＋鸡肝＋鸡心，动物物种、脂肪酸、碘、锰和某些维生素来源仍然单一。

## 六、永远的爱犬路线

### 6.1 官方鸡肉全阶段犬食谱

《The Forever Dog Life》公开的全生命阶段鸡肉犬食谱，可视为该路线最清晰的一级证据，而不是网上流传的“肉50%、内脏10%、蔬菜30%、油脂5%、水果5%”。

### 6.2 如何借鉴，而不是照抄

永远的爱犬路线可以概括为：

- 以多样动物蛋白为中心；
- 内脏既提供维生素/矿物质，也提供生物活性营养；
- 少量鱼和贝类承担脂肪酸及微量元素功能；
- 绿叶蔬菜提供植物化学物、纤维和体积；
- 使用海藻、洋车前子、盐及骨粉等补充体系；
- 避免把新鲜食材简单理解为“少加工”或“无补剂”。

其官方犬食谱鱼＋贝类合计约10%，但不是每天50%鱼。若猫模板也按“5%鱼＋5%贝类”执行，仍应核对碘、硫胺素、牛磺酸和维生素E，不能因为比例低就默认安全。

## 七、生食改良熟制路线

这条路线不是新的“作者命名标准”，而是工程上最实用的skill分类：保留BARF、PMR或永远爱犬的食材结构和轮换逻辑，但把肉、鱼、蛋和植物全熟化，再重建补充体系。

### 7.1 熟制后必须重算的项目

| 项目 | 熟制影响与处理 |
|---|---|
| 钙 | 肉高磷低钙，无骨时必须补；熟骨不能替代 |
| 磷 | 来自肉、内脏和鱼，是钙添加量的计算基础 |
| 牛磺酸 | 猫必须检查；高温、研磨和储存均可能增加风险 |
| 硫胺素 | 鱼、发酵和热处理相关，不宜长期高频喂高鱼餐 |
| 维生素E | 高鱼或多不饱和脂肪酸增加时，需要相应评估 |
| 碘 | 海藻是来源之一，但剂量不能凭“一小撮” |
| 维生素A/D | 肝脏提供大量维生素A；维生素D应纳入配方核算 |
| 脂肪酸 | 鱼油不是越多越好，需要平衡EPA/DHA与维生素E |
| 卫生 | 熟制降低部分风险，仍需控制交叉污染、冷藏和复热 |

## 八、肉类版与鱼类版的统一比例区间

下面按“纯肌肉肉/主要肉源”与“全部动物组织”分别给出，避免口径混乱。

| 路线 | 犬纯肉 | 犬全部动物组织 | 猫纯肉 | 猫全部动物组织 |
|---|---:|---:|---:|---:|
| 临床营养学 | 13%–75% | 约30%–80% | 约69%（肝主导配方）至75% | 约69%–85% |
| BARF | 55%–65% | 约70%–85% | 65%–75% | 约80%–90% |
| PMR | 60%–70% | 约75%–85% | 70%–80% | 约85%–95% |

## 九、蛋白质、脂肪和碳水口径

### 9.1 犬

犬可耐受比猫更宽的碳水范围。公开临床教材中的成年犬低脂配方ME约398 kcal/100g，干物质约22.6%蛋白质、8.0%脂肪；永远的爱犬官方食谱则为47.14%蛋白质ME、48.21%脂肪ME、4.66%净碳水ME。

因此犬熟自制至少可分为：

- **商业营养档案型**：熟碳水可占湿重25%–50%；
- **均衡鲜食型**：熟碳水约5%–20%；
- **高肉低加工型**：净碳水接近0%–10%ME；
- **永远爱犬型**：通常约0%–10%净碳水ME，但蔬菜仍可能占约20%湿重。

无论哪种，都需同时满足蛋白质、脂肪、钙磷和微量营养目标。

### 9.2 猫

猫是专性食肉动物，但仍可在营养均衡前提下摄入少量熟淀粉。永远的爱犬官方犬食谱净碳水也只有4.66%ME，说明高肉路线不必然依赖大量谷物。

猫熟自制的合理起点：

- 蛋白质ME：约45%–55%
- 脂肪ME：约35%–50%
- 碳水ME：通常0%–15%，疾病状态另算
- 牛磺酸：独立核算，不能只靠“含肉”
- 钙磷：独立核算，不能只写“已加钙粉”

上述是配方设计区间，不是官方最低需求换算值。具体动物需依据体重、ME系数、生命阶段、疾病状态和食材数据库逐项核算。

## 十、鱼和贝类的使用边界

### 10.1 鱼

- 偶尔轮换：单次5%–10%
- 每周1–2次脂肪酸餐：单次5%–10%
- 作为固定鱼基主餐：不应超过总湿重30%–40%
- 高汞鱼：仅作小量、低频轮换，不宜长期日粮主体
- 熟制鱼类：仍需关注牛磺酸、硫胺素、碘、维生素E和脂肪酸平衡
- 鱼油：不是鱼的主要替代物；两者营养组成不同

### 10.2 贝类

永远的爱犬官方犬食谱使用4.8%罐头牡蛎，其主要价值是提供特定微量元素，而不是钙。贝类同样存在批次、产地、重金属和污染物差异。

建议：

- 贝类0%–5%
- 不作为唯一动物蛋白
- 碘海藻和贝类同时存在时，要核对总碘，不能叠加“天然”来源
- 肝病、肾病、甲状腺异常动物须个体化，不应照搬健康动物模板

## 十一、证据等级

skill在调用每个模板时，应同时返回证据等级，不能只返回比例。

| 等级 | 定义 | 示例 |
|---|---|---|
| A | 原始营养需要、法规标准、同行评审或权威机构资料 | NRC营养需要；AAFCO/FEDIAF；兽医临床营养教材；AAHA |
| B | 作者团队或专业机构使用数据库完整核算的公开配方 | 永远的爱犬官方配方 |
| C | 行业/品牌广泛采用的结构，但生熟转换和动物个体证据有限 | 常见BARF、PMR模板 |
| D | 网络经验、品牌商品模板或食材数据库估算 | 社区“80/10/10”、单一原料占比建议 |

永远的爱犬食谱是B级，不是A级；常见“80/10/10”是C级；网络流传的固定每500g加钙量多为D级，除非明确来自某个完整配方和ME核算。

### 12.2 禁止自动生成的场景

出现以下任一条件时，应拒绝输出“全价配方”，只提供通用营养说明：

- 未提供物种、体重或生命阶段；
- 幼犬/幼猫、孕期或哺乳期；
- 肾病、肝病、糖尿病、泌尿结石、心脏病、胰腺炎或食物过敏；
- 需要减重但未提供目标体重和当前体况；
- 拟用生骨肉，但要求熟制后继续按原骨比例制作；
- 鱼类超过40%、肝脏超过15%或蔬菜超过50%；
- 没有钙、碘、维生素E、牛磺酸等核算信息却宣称全价。

## 十四、最终执行规则

1. 用户没有说明路线时，不要默认“永远的爱犬”，应先询问或返回多路线对比。
2. 用户只给肉类比例时，必须追问是否包含肝脏、心脏、鱼和带骨肉。
3. 犬猫不能用同一配方比例；鱼基配方必须单列。
4. 熟制配方不能直接照抄BARF/PMR生食百分比。
5. 肝脏5%–10%可作为常规起点，但不能无限轮换到15%以上而不核算维生素A。
6. 鱼5%–10%适合单次轮换；长期鱼主粮应控制在30%–40%以内并专项核算。
7. “高肉”不等于“肉越多越好”；应同时满足钙、磷、牛磺酸、脂肪酸和微量营养目标。
8. 所有A/B级结论应标注来源；C/D级模板只作为采购与初筛结构，不作为个体营养承诺。
9. 幼宠、孕宠、老年及疾病动物不套用本文件的通用区间。
10. 最可靠的熟自制是“营养师配方＋食材批次数据库＋必要时送检＋临床随访”，而不是复制某个网红百分比。
