## 一、必需营养补充剂（基础配方层）

> 来源：祖先饮食配方 食谱 + 自制食谱模板 食谱
> 这些是自制犬食中**必须添加**的营养素，食物本身通常无法满足NRC标准

### 1.1 钙 (Calcium)

| 来源 | 剂量 | 适用场景 | 备注 |
|------|------|----------|------|
| 骨粉 (Bonemeal) | 肉重的 1%（成犬）或 1.5%（幼犬） | 无骨肉食谱 | 人用级无铅骨粉或MCHA |
| 骨粉 (Bonemeal) | 1½ oz / 4磅肉 (42g) | 祖先饮食配方 牛肉食谱 | 满足幼犬NRC标准 |
| 蛋壳粉 (Eggshell Powder) | 1 茶匙 = 1,500 mg 钙 | 无骨肉食谱 | 1茶匙蛋壳粉 = 1½-2茶匙骨粉 |
| 蛋壳粉 (自制食谱模板) | 16-17 g / 食谱 | 每个食谱（约4,000 kcal） | 标准用量 |
| 天然骨头 | 按食谱比例使用 | 带骨禽类食谱 | 必须生食，煮熟骨头危险 |
| 磷酸二钙 | 按需计算 | 无骨肉食谱替代 | 骨粉替代品 |

**计算公式**：
- 无骨肉：Ca需求 = 1.0 g/1000 kcal（成犬）或 3.0 g/1000 kcal（幼犬）
- 骨粉用量 = 肉重 × 1% (成犬) 或 × 1.5% (幼犬)
- 蛋壳粉换算：1 茶匙(5g)蛋壳粉 ≈ 1,500 mg 钙

### 1.2 磷 (Phosphorus)

| 来源 | 说明 |
|------|------|
| 骨粉 | 同时提供钙和磷 |
| 肉类本身 | 含有天然磷 |
| 磷酸二钙 | 补充品替代 |
| 带骨肉 | 骨头含天然磷 |

**Ca:P 比例目标**：1.2:1 至 1.7:1（祖先饮食为 1.7:1）

### 1.3 碘 (Iodine)

| 来源 | 剂量 | 含碘量 | 适用场景 |
|------|------|--------|----------|
| 加碘盐 | 1-2 茶匙 (4-8 g) | 0.1 mg/g | 祖先饮食配方 牛肉/混合食谱 |
| 海藻粉 (Kelp) | ¼ 茶匙 | 0.06% 碘 = 600 mcg/¼茶匙 | 祖先饮食配方 鸡肉食谱 |
| 海藻粉 (Kelp) | 1 克 | 700 mcg 碘/g | 自制食谱模板 标准用量 |
| 天然食物 | 沙丁鱼、牡蛎、牛肝 | 含量不确定 | 辅助来源 |

**NRC 需求**：0.22 mg/1000 kcal（成犬和幼犬相同）

**注意事项**：
- 海藻含砷较高，不宜每天食用
- 2 茶匙加碘盐可确保满足NRC推荐
- 1 茶匙加碘盐可能足够，2 茶匙保险

### 1.4 锰 (Manganese)

| 来源 | 剂量 | 适用场景 |
|------|------|----------|
| 菠菜 | 1 磅 / 4,000 kcal 食谱 | 祖先饮食配方 牛肉食谱 |
| 红薯 + 西兰花茎 | 各 ½ 磅 | 祖先饮食配方 鸡肉食谱 |
| 燕麦麸（煮熟） | ½ 磅 或 2 oz(干) | 祖先饮食配方 完美食谱 |
| 亚麻籽（现磨） | 2 oz (56 g) | 鸡肉食谱（比奇亚籽含锰多50%） |
| 海藻粉 | ¼-1 茶匙 | 高锰海藻品种 |
| 锰补充剂 | 3 mg | 菠菜不耐受时的替代 |

**NRC 需求**：1.2 mg/1000 kcal（成犬），1.4 mg/1000 kcal（幼犬）

### 1.5 维生素 E (Vitamin E)

| 场景 | 食谱PUFA含量 | 额外需求 | 剂量 |
|------|-------------|----------|------|
| 低PUFA食谱（牛肉） | 6 g/1000 kcal | 不需要额外 | 食材（菠菜）足够 |
| 高PUFA食谱（鸡肉） | 13 g/1000 kcal | 需额外 40-44 IU | 2 滴天然维生素E (40 IU) |
| 混合食谱 | 9 g/1000 kcal | 需额外补充 | 2 滴 (40 IU) |
| 低脂食谱 | ~22 g/1000 kcal | 需要更多 | 40-200 IU |
| 自制食谱模板 | — | 标准添加 | 通常2滴(40 IU) |

**计算公式**：
- NRC基础需求：11.3 IU/1000 kcal
- PUFA补偿：每增加 1 g PUFA/1000 kcal 需约 2.5 IU 额外维生素E
- 总需求 = 11.3 + (PUFA量 - 5) × 2.5
- **天然来源**：菠菜、杏仁（3颗现磨 = 20 IU）、核桃、麦芽油（2茶匙 = 40 IU）

### 1.6 维生素 D (Vitamin D)

| 来源 | 说明 |
|------|------|
| 沙丁鱼 | 主要来源，1罐(3.75oz)足够 |
| 肝脏 | 可靠来源 |
| 牡蛎 | 辅助来源 |
| 鱼肝油 | ¼ 茶匙（低脂食谱中） |

**NRC 需求**：136 IU/1000 kcal
**注意**：没有沙丁鱼和肝脏，维生素D很可能不足。但脂溶性维生素A和D容易过量有毒，补充前应检查血检。

### 1.7 牛磺酸 (Taurine) — 自制食谱模板 标准

| 来源 | 剂量 | 说明 |
|------|------|------|
| 自制食谱模板 标准 | 2,500 mg / 食谱（约4,000 kcal） | 每个食谱统一添加 |
| 天然来源 | 心脏、肝脏、沙丁鱼 | 食材含天然牛磺酸 |

**换算**：约 625 mg/1000 kcal

**注意**：牛磺酸对心脏健康至关重要，某些品种（金毛、可卡等）易缺乏

### 1.8 胆碱 (Choline) — 自制食谱模板 标准

| 来源 | 剂量 | 说明 |
|------|------|------|
| 自制食谱模板 标准 | 6,000-7,500 mg / 食谱（约4,000 kcal） | 大多数食谱用7,500 mg |
| 自制食谱模板（部分食谱） | 6,000 mg | 少量食谱使用较低剂量 |
| 天然来源 | 蛋黄、肝脏 | 鸡蛋含天然胆碱 |

**换算**：约 1,500-1,875 mg/1000 kcal
**NRC 需求**：425 mg/1000 kcal（成犬和幼犬）

### 1.9 铜 (Copper) 和 锌 (Zinc)

| 来源 | 剂量 | 说明 |
|------|------|------|
| 牡蛎 | ¼ 磅 (113 g) 鲜或 3.5 oz 罐头 | 首选天然来源 |
| 牛肝 | ¼ 磅 | 含铜量为鸡肝的10倍 |
| 补充剂 | 5 mg 铜 + 25 mg 锌 | 牡蛎替代方案 |

**NRC 需求**：
- 铜：1.5 mg/1000 kcal（成犬），2.7 mg/1000 kcal（幼犬）
- 锌：15 mg/1000 kcal（成犬），25 mg/1000 kcal（幼犬）

**品种注意**：大麦町犬、贝灵顿梗可能需要低铜饮食 → 用鸡肝替代牛肝

### 1.10 必需脂肪酸 (EPA + DHA)

| 来源 | 剂量 | 说明 |
|------|------|------|
| 沙丁鱼（水浸无盐） | 1 罐 3.75 oz (106 g) | 祖先饮食配方 所有食谱标准 |
| 牡蛎 | ¼ 磅 (113 g) | 鸡肉和混合食谱 |
| 亚麻籽（现磨） | 2 oz (56 g) | 提供ALA（短链omega-3） |
| 奇亚籽（现磨） | 2 oz (56 g) | 混合食谱用 |
| 大麻籽油 | 4 茶匙 (16 g) | 牛肉食谱用 |
| 鱼油 | 按需计算 | 长寿饮食研究 功能性补充剂 |

## 二、功能性补充剂（健康优化层）

> 来源：《永远的爱犬》第8章
> 分为"核心要素"和"可选附加项"

### 2.1 核心长寿补充剂

#### 白藜芦醇 (Resveratrol)

| 项目 | 内容 |
|------|------|
| 来源 | 虎杖根部提取 |
| 功效 | 抗炎、抗氧化、抗癌、心血管保护、增强神经功能 |
| 剂量范围 | 5-300 mg/kg体重/天 |
| 推荐剂量 | 100 mg/kg体重/天，分散加入食物中 |
| 使用方式 | 间歇疗法（每隔几天服用一次） |
| 注意 | 不喂葡萄（有毒）；使用安全来源的白藜芦醇 |

#### 姜黄素 (Curcumin)

| 项目 | 内容 |
|------|------|
| 来源 | 姜黄 |
| 功效 | 天然抗炎、抗氧化、抗癌、脂肪代谢帮手、神经保护 |
| 剂量 | 每次 50-250 mg，每天两次（约 2 mg/磅体重/次，每天两次） |
| 替代 | 每天在狗粮中添加新鲜姜黄（但浓度较低） |
| 使用方式 | 间歇疗法 |

#### 益生菌 (Probiotics)

| 项目 | 内容 |
|------|------|
| 功效 | 肠道微生物多样化、免疫系统支持 |
| 选择标准 | CFU值高、多种益生菌混合、第三方验证 |
| 使用方式 | 轮流使用不同品牌和类型（土壤/原生孢子+不同菌株） |
| 食物来源 | 发酵蔬菜、无添加开菲尔 |
| 搭配 | 益生元食物 + 益生菌 = 后生元 |
| 剂量 | 按产品包装说明 |

#### 必需脂肪酸 EPA + DHA (功能性)

| 项目 | 内容 |
|------|------|
| 适用场景 | 狗狗不吃富含脂肪的鱼（每周2-3次）时 |
| 来源 | 鲑鱼、磷虾、凤尾鱼、贻贝、鱿鱼油 |
| 形式要求 | 甘油三酯或磷脂形式（非脂肪酸乙酯） |
| 健康狗维持剂量 | 75 mg/kg体重/天 (EPA+DHA合计) |
| 疾病治疗剂量 | 50-220 mg/kg体重/天 |
| 骨关节炎最高剂量 | 220 mg/kg体重/天 |
| 储存 | 冰箱保存，开封后30天内用完 |
| 注意 | 鱼肝油 ≠ 鱼油（鱼肝油含VA/VD，不含omega-3） |

#### 槲皮素 (Quercetin)

| 项目 | 内容 |
|------|------|
| 功效 | 天然抗组胺（抗过敏）、抗氧化、抗炎、免疫调节 |
| 剂量计算 | 体重(磅) × 8 = 每日mg数 |
| 示例 | 50磅狗 = 400 mg/天；125磅狗 = 1,000 mg/天 |
| 服用方式 | 每天分两份，不同时间服用 |
| 加倍情况 | 宠物状态很差时可加倍 |
| 天然来源 | 苹果、浆果、绿叶蔬菜（但量不够，需补充剂） |

#### 烟酰胺核糖 (NR) / 烟酰胺单核苷酸 (NMN)

| 项目 | 内容 |
|------|------|
| 功效 | NAD+前体，抗衰老，改善能量代谢和胰岛素敏感性 |
| 推荐剂量 | 2 mg/磅体重/天 (约4.4 mg/kg) |
| 高剂量 | 32 mg/kg体重/天（动物研究显示更大益处） |
| 常见产品剂量 | 300 mg/天 |
| 使用建议 | 从低剂量开始，经济允许时增加 |

#### 猴头菇 (Lion's Mane)

| 项目 | 内容 |
|------|------|
| 功效 | 认知增强、适应原、胃肠保护、神经保护 |
| 适用 | 7岁以上宠物优先 |
| 剂量 | 1,000 mg / 50磅体重/天 |
| 使用场景 | 退行性脊髓病风险犬类、胃肠道问题 |

#### 谷胱甘肽 (Glutathione)

| 项目 | 内容 |
|------|------|
| 功效 | 主要抗氧化剂、解毒、清除AGEs、重金属螯合 |
| 剂量 | 2-4 mg/磅体重/天 (4.4-8.8 mg/kg) |
| 参考剂量 | 健康：250-500 mg/天（人）；狗按体重换算 |
| 使用方式 | 两餐之间加在肉丸或零食中 |
| 替代 | 混合药用蘑菇（促进身体自行产生谷胱甘肽） |

### 2.2 治疗性/条件性补充剂

#### SAMe (S-腺苷蛋氨酸)

| 项目 | 内容 |
|------|------|
| 适用场景 | 接触大量化学物质（草坪护理产品、家庭清洁剂） |
| 功效 | 肝脏解毒、DNA修复、抗抑郁、止痛、认知功能 |
| 剂量 | 15-20 mg/kg体重，每日一次 |
| 使用方式 | 两餐之间，放在小肉丸中（吸收最好） |
| 效果周期 | 4-8周后问题行为减少44% |
| 注意 | 不要加入大量食物中 |

#### 水飞蓟/乳蓟 (Milk Thistle / Silymarin)

| 项目 | 内容 |
|------|------|
| 适用场景 | 使用驱虫药、心丝虫药、跳蚤/蜱虫药后 |
| 功效 | 肝脏排毒首选、清除药物残留、抗癌 |
| 剂量 | 1/8 茶匙 / 10磅体重 |
| 使用方式 | 短期集中喂服：连续一周每天一次 |
| 触发时机 | 心丝虫药后、草坪化学品接触后 |
| 注意 | 人用产品需先咨询兽医 |

#### 青口贝 (Green-Lipped Mussel, GLM)

| 项目 | 内容 |
|------|------|
| 适用场景 | 关节支持（从幼犬关节损伤到老年关节退化） |
| 功效 | 天然NSAIDs替代品、缓解骨关节炎 |
| 剂量 | 15 mg/磅体重/天 (33 mg/kg) |
| 研究支持 | 125 mg/天，8周以上显著改善（81只狗双盲研究） |
| 形式 | 冻干零食 或 粉末补充剂 |
| 额外益处 | 含EPA和DHA |

#### L-茶氨酸 (L-Theanine)

| 形式选择 | 油基软胶囊/滴液 > 结晶粉末（生物利用度更高） |
| 搭配 | 搭配1茶匙椰子油提高吸收 |

## 三、补充剂分类速查表

### 3.1 按使用场景分类

| 场景 | 推荐补充剂 |
|------|-----------|
| **基础营养（所有自制食谱）** | 钙（骨粉/蛋壳粉）、碘（加碘盐/海藻粉）、锰（蔬菜/补充剂）、维生素E |
| **核心长寿（所有狗考虑）** | 白藜芦醇、姜黄素、益生菌、EPA+DHA、槲皮素、NR/NMN、猴头菇(7岁+)、谷胱甘肽 |

### 3.2 按剂量计算方式分类

| 计算方式 | 补充剂 |

### 3.3 使用原则

1. **间歇疗法**：大多数功能性补充剂不需要每天服用，每周几次即可。改变品牌和频率可优化反应
2. **食物优先**：先纠正饮食结构，再考虑补充剂。能从食物获取的尽量从食物获取
3. **协同作用**：益生元 + 益生菌 = 后生元；多酚 + 益生菌效果更好
4. **避免过量**：抗氧化剂过量会妨碍身体自身抗氧化机制；脂溶性维生素(A/D)易有毒
5. **兽医咨询**：有确诊病症、正在服药、或计划手术的狗，使用新补充剂前咨询兽医
6. **喂服技巧**：藏在肉丸、杏仁酱或新鲜奶酪中，不要强迫咽下松散粉末

## 五、配方补充剂添加决策树

```
自制食谱完成基础食材后 → 检查以下补充需求：

1. 是否含骨？
   ├─ 是 → 跳过钙补充
   └─ 否 → 添加骨粉(肉重1-1.5%) 或 蛋壳粉(1茶匙/1500mg钙)

2. 碘来源是否足够？
   ├─ 有沙丁鱼+肝脏+牡蛎 → 可能足够，加1茶匙加碘盐保险
   └─ 缺少上述食材 → 加2茶匙加碘盐 或 ¼-1茶匙海藻粉

3. 锰来源是否足够？
   ├─ 有菠菜/红薯/燕麦麸 → 通常足够
   └─ 缺少上述食材 → 添加3mg锰补充剂 或 2oz燕麦麸

4. PUFA含量水平？
   ├─ 低PUFA（牛肉食谱, ~6g/1000kcal）→ 维生素E通常足够
   └─ 高PUFA（鸡肉食谱, ~13g/1000kcal）→ 需额外40-44 IU维生素E

5. 维生素D来源？
   ├─ 有沙丁鱼+肝脏 → 足够
   └─ 缺少 → 需额外补充维生素D

6. 食谱是否包含以下自制食谱模板标准补充剂？
   ├─ 蛋壳粉 16-17g（无骨食谱）
   ├─ 海藻粉 1g（碘来源）
   ├─ 牛磺酸 2,500mg
   └─ 胆碱 6,000-7,500mg

7. 功能性补充剂（按需添加）→ 参见第三节分类速查表
```
