# 猫（Feline）营养需求数据汇总

来源：NRC《犬猫营养需要》(2006)

---

## 一、能量需求

### 基本公式与系数

| 指标 | 公式/系数 | 说明 |
|------|----------|------|
| **静息能量（RER）基础** | 以BW^0.67为代谢体重 | 猫理论种内异速生长系数为0.67 |
| **成年维持MER（瘦型猫）** | 100 kcal ME/kg BW^0.67 | 约70 kcal/kg BW；适用于BCS≤5（9分制） |
| **成年维持MER（超重猫）** | 130 kcal ME/kg BW^0.4 | BCS>5时适用 |
| **妊娠期** | ≈140 kcal ME/kg BW^0.67 | 妊娠期体重增长40%~50% |
| **泌乳期** | 维持需要的2~2.5倍 | 哺育>2只幼猫时；高适口性、≥4 kcal ME/g DM，自由采食 |
| **生长（断奶后）** | ME=维持量×2.5×[e^(−0.1x)−0.1] | x=实际体重/成年理想体重；新生幼猫20~25 kcal/100g BW |

> **注**：假定标准：成年猫4 kg，日消耗250 kcal ME；幼猫800 g，日消耗180 kcal ME；泌乳母猫4 kg哺育4只幼猫，日消耗540 kcal ME。

## 三、维生素需求

### 脂溶性维生素

| 维生素 | 单位 | 生长/维持 | 妊娠/泌乳 | 备注 |
|--------|------|-----------|-----------|------|
| **维生素A（视黄醇）** | ug/1000 kcal | 200 (AI) | 400 | **猫必须预成型VA**，不能利用类胡萝卜素转化 |
| 维生素D（胆钙化醇） | ug/1000 kcal | 1.4 (RA) | 1.4 | D3比D2活性高；幼猫MR约0.7 ug/1000 kcal |
| 维生素E（α-生育酚） | mg/1000 kcal | 6 (RA) | - | 低脂肪日粮（≤10%）；高PUFA日粮需≥30 mg/kg；生育酚(mg)/PUFAs(g)≥0.6 |
| 维生素K | mg/kg日粮 | 1.0 (AI) | - | 含鱼猫粮需额外添加甲萘醌；无鱼日粮肠道菌群可满足 |

## 四、必需氨基酸需求

### 生长幼猫氨基酸需要量（代谢能4.0 kcal/g日粮基础）

| 氨基酸 | MR (g/kg日粮) | 商品日粮常用量 (g/kg) | 备注 |
|--------|---------------|----------------------|------|
| 精氨酸 | 7.7 | ~10 | 粗蛋白200 g/kg时；高蛋白每增1 g需加0.02 g精氨酸 |
| 组氨酸 | 2.6 | 4.7 | 2 g/kg可满足增重，3 g/kg才满足血红蛋白 |
| 异亮氨酸 | 4.3 | 7.7 | |
| 亮氨酸 | 10.2 | 18 | |
| 赖氨酸 | 6.8 | 12 | |
| 蛋氨酸+胱氨酸 | ~3.5 (蛋氨酸) | ~7.7 (总含硫AA) | 胱氨酸可替代约50%蛋氨酸需要 |
| 苯丙氨酸+酪氨酸 | 15.3 | 15.8 | 维持黑色被毛需更高；酪氨酸可替代约50%苯丙氨酸 |
| 苏氨酸 | 5.2 | 10.8 | |
| 色氨酸 | 1.3 | 1.9 | SUL: 15 g/kg |
| 缬氨酸 | 5.1 | 10 | |
| **牛磺酸** | **320~425 mg/kg** | **1000~2000 mg/kg** | **猫必需！** 纯合日粮MR：生长320、维持320、妊娠425、泌乳425 mg/kg；商品日粮因纤维/蛋白消化率差异需更高 |

> **重要特点**：猫对精氨酸缺乏极度敏感（1~3 h内高血氨）；牛磺酸缺乏导致视网膜退化、扩张型心肌病、繁殖障碍。

## 五、必需脂肪酸需求

| 脂肪酸 | 成年维持 | 生长/繁殖 | 备注 |
|--------|---------|-----------|------|
| **总脂肪** | 9% DM (22.5 g/1000 kcal) | ≥9% DM | MR/AI |
| **亚油酸（LA, n-6）** | 0.55% DM (1.4 g/1000 kcal) | ~1.4 g/1000 kcal | RA |
| **花生四烯酸（AA, n-6）** | 0.02% DM (AI), 0.06% DM (RA) | 0.02% DM (RA) | **猫不能由LA有效合成AA**，必须日粮提供；高n-3 LCPUFA时需增加AA |
| α-亚麻酸（ALA, n-3） | 无确定MR | 0.02% DM (AI) | 猫Δ6脱饱和酶活性低，ALA转化n-3 LCPUFA有限 |
| **EPA+DHA (n-3)** | 0.1 g/kg DM (AI) | 0.01%~0.03% DM (AI) | 主要来自DHA；妊娠泌乳期对胎儿/幼猫脑和视网膜发育重要 |

## 六、蛋白质需求

| 生理阶段 | MR (g/kg日粮, 4.0 kcal/g) | RA/AI (g/kg日粮) | 商品干膨化日粮 |
|----------|---------------------------|------------------|---------------|
| 生长幼猫 | ~180 | - | ~280 |
| 成年维持 | ~160 | 200 | ≥265 |
| 妊娠/泌乳 | - | - | 生长期水平可满足 |

> 猫为专性肉食动物，高蛋白需求源于不能有效下调肝脏氮分解酶。

## 七、安全上限（SUL）汇总

| 营养物质 | SUL估算值 | 说明 |
|----------|----------|------|
| 维生素A | 20000 ug/1000 kcal | 约为RA的100倍；>306000 ug/kg引起骨骼病变 |
| 维生素D | 未确定 | 商品猫粮含1300~1600 ug/kg DM可致中毒 |
| 钙 | 2.6~4.6 g/1000 kcal | 高钙降低采食量和生长率 |
| 磷 | 10~14 g/kg (4000 kcal/kg) | 钙磷比合理时 |
| 镁 | ~1 g/kg DM | 与鸟粪石尿结石相关；低尿pH可降低风险 |
| 钠 | >10 g/kg DM | 充足饮水下安全 |
| 亚油酸 | 13.8 g/1000 kcal | |
| 花生四烯酸 | 2 g/kg (0.2% DM) | |
| 色氨酸 | 15 g/kg日粮 | 60 g/kg可致死 |
| 赖氨酸 | >58 g/kg日粮 | |
| 蛋氨酸 | <4.7 g/kg (DL型) | |
| 牛磺酸 | 未确定 | |

> 多数维生素B族、铜、铁、锌、锰、硒、碘的安全上限未在猫中系统研究。
