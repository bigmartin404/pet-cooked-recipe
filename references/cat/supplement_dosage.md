> 来源：

> 2. FEDIAF 2024 营养指南 — 猫营养标准
> 3. 临床兽医营养学 — 补充剂使用指南

## 一、必需营养补充剂（基础配方层）

猫为专性肉食动物，以下营养素在自制饮食中通常需要额外补充：

### 1.1 牛磺酸 (Taurine) — **猫必需！**

| 项目 | 内容 |
|------|------|
| NRC需求 | 生长320mg/kg、维持320mg/kg、妊娠425mg/kg、泌乳425mg/kg（纯合日粮） |
| 商品日粮常用量 | 1000-2000 mg/kg（因纤维/蛋白消化率差异需更高） |
| FEDIAF标准（干粮） | 0.10 g/100g DM ≈ 0.25 g/1000 kcal |
| FEDIAF标准（湿粮） | 0.20 g/100g DM ≈ 0.50 g/1000 kcal |
| 自制推荐量 | 500 mg / 1000 kcal（蒸煮需补更多，因热加工损失） |
| 天然来源 | 心脏、肝脏、肾脏、沙丁鱼、贻贝 |
| 缺乏后果 | 中心性视网膜退化、扩张型心肌病(DCM)、繁殖障碍 |
| 安全上限 | 未确定，一般认为较安全 |

> ⚠️ 蒸煮会导致牛磺酸大量流失（煮倒汤可损失60-70%），自制熟粮必须额外补充牛磺酸。

### 1.2 钙 (Calcium)

| 项目 | 成年维持 | 生长幼猫 | 妊娠/泌乳 |
|------|---------|---------|----------|
| NRC RA | 720 mg/1000 kcal | 2000 mg/1000 kcal | 2700 mg/1000 kcal |
| FEDIAF | 1000 mg/1000 kcal (MER100) | 2500 mg/1000 kcal | — |
| 推荐补充方式 | 骨粉（肉重的1%）或蛋壳粉 | 骨粉（肉重的1.5%） | 骨粉（肉重的2%） |
| 蛋壳粉换算 | 1茶匙(5g) ≈ 1500 mg钙 | — | — |

> 猫钙磷比推荐范围：1:0.6 ~ 1:1.3

### 1.3 磷 (Phosphorus)

| 项目 | 成年维持 | 生长幼猫 |
|------|---------|---------|
| NRC RA | 640 mg/1000 kcal | 1800 mg/1000 kcal |
| FEDIAF | 640 mg/1000 kcal (MER100) | 2100 mg/1000 kcal |

> 肉类和骨头本身含丰富磷，自制饮食中磷通常不缺乏。肾病猫需限制磷摄入。

### 1.4 维生素A — **猫必须预成型VA！**

| 项目 | 内容 |
|------|------|
| NRC AI | 200 μg/1000 kcal（生长/维持），400 μg/1000 kcal（妊娠/泌乳） |
| FEDIAF | 833 IU/1000 kcal (MER100) = 250 μg RE |
| 猫特殊性 | **猫不能将β-胡萝卜素转化为维生素A**，必须从动物组织获取预成型VA |
| 天然来源 | 肝脏（极佳来源）、蛋黄、鱼油、乳制品 |
| 安全上限 | 20,000 μg/1000 kcal（约RA的100倍） |
| 中毒症状 | >306,000 μg/kg DM可致骨骼病变 |

> ⚠️ 自制饮食中含肝脏即可提供充足VA，一般不需额外补充。但注意不要过量。

### 1.5 维生素D

| 项目 | 内容 |
|------|------|
| NRC RA | 1.4 μg/1000 kcal |
| FEDIAF | 62.5 IU/1000 kcal (MER100) = 1.56 μg |
| 猫特殊性 | 猫皮肤合成VD能力有限，主要依赖食物来源 |
| 天然来源 | 鱼肝油、沙丁鱼、蛋黄、肝脏 |
| 安全上限 | 欧盟法定上限 227 IU/100g DM；高剂量可致中毒 |

### 1.6 维生素E

| 项目 | 内容 |
|------|------|
| NRC RA | 6 mg/1000 kcal |
| FEDIAF | 9.5 IU/1000 kcal (MER100) ≈ 6.3 mg |
| PUFA补偿 | 高PUFA日粮需≥30 mg/kg；生育酚(mg)/PUFAs(g) ≥ 0.6 |
| 天然来源 | 小麦胚芽、葵花籽、杏仁、菠菜 |
| 缺乏后果 | 黄脂病（steatitis）、肌肉萎缩、生殖障碍 |

### 1.7 烟酸 (Niacin / Vitamin B3) — **猫必须！**

| 项目 | 内容 |
|------|------|
| NRC MR | 8.0 mg/1000 kcal |
| FEDIAF | 3.2 mg/1000 kcal (MER100) |
| 猫特殊性 | **猫不能由色氨酸合成烟酸**，必须从日粮获取 |
| 天然来源 | 肝脏、心脏、肾脏、鱼类、花生 |
| 缺乏后果 | 口腔黏膜炎、腹泻、体重下降 |

### 1.8 精氨酸 (Arginine) — **猫必须！**

| 项目 | 内容 |
|------|------|
| NRC MR | 7.7 g/kg日粮（200g蛋白基础） |
| FEDIAF | 2.5 g/1000 kcal (MER100) |
| 猫特殊性 | **猫对精氨酸缺乏极度敏感**，缺精氨酸1-3小时内即可出现高血氨症状 |
| 高蛋白需额外精氨酸 | 蛋白每增加1g需额外加0.02g精氨酸 |
| 天然来源 | 动物蛋白普遍含精氨酸，充足的动物蛋白饮食通常足够 |
| 安全上限 | 生长猫 3.5 g/100g DM（营养安全上限） |

### 1.9 花生四烯酸 (AA, omega-6) — **猫必须！**

| 项目 | 内容 |
|------|------|
| NRC RA | 约50 mg/1000 kcal（成年） |
| FEDIAF | 15 mg/1000 kcal (MER100) 成年；50 mg/1000 kcal 生长/繁殖 |
| 猫特殊性 | **猫缺乏Δ-6去饱和酶，不能由亚油酸有效合成AA**，必须日粮提供 |
| 天然来源 | 蛋黄、动物脂肪、肝脏 |
| 繁殖期需求 | 约为成年的3倍，支持胎儿发育和泌乳 |
| 安全上限 | 2 g/kg (0.2% DM) |

### 1.10 碘 (Iodine)

| 项目 | 成年维持 | 生长/繁殖 |
|------|---------|----------|
| NRC RA | 350 μg/1000 kcal | 450 μg/1000 kcal |
| FEDIAF | 130 μg/1000 kcal (MER100) | 180 μg/1000 kcal |
| 安全上限 | 2200 μg/1000 kcal (NRC SUL) | 同上 |
| 推荐来源 | 海藻粉少量(需核对碘含量) 或 鳕鱼/鲱鱼50-80g | 同左 |

> ⚠️ **不推荐使用加碘盐作为猫碘源**，原因同犬：钠过高（猫对钠更敏感）、碘含量不稳定、非宠物专用
> ⚠️ 海藻粉碘含量波动极大（500-8000µg/g），猫体型小更容易过量，必须选择标明碘含量的品牌

### 1.11 胆碱 (Choline)

| 项目 | 内容 |
|------|------|
| NRC MR | 510 mg/1000 kcal（生长猫） |
| FEDIAF | 240 mg/1000 kcal (MER100) |
| 天然来源 | 蛋黄（极佳来源）、肝脏、大豆卵磷脂 |
| 缺乏后果 | 脂肪肝、肝功能障碍 |

## 三、猫特有营养需求速查

| 营养素 | 猫必须？ | 犬是否必须 | 原因 |
|--------|---------|-----------|------|
| 牛磺酸 | ✅ 必需 | ❌ 可自身合成 | 猫合成酶活性不足 |
| 花生四烯酸(AA) | ✅ 必需 | ❌ 可由LA合成 | 猫缺乏Δ-6去饱和酶 |
| 预成型维生素A | ✅ 必需 | ❌ 可由β-胡萝卜素转化 | 猫缺乏转化酶 |
| 烟酸 | ✅ 必需（高量） | ⚠️ 可由色氨酸合成 | 猫不能由色氨酸合成 |
| 精氨酸 | ✅ 必需（敏感） | ✅ 必需（不敏感） | 猫尿素循环酶活性高，缺精氨酸很快高血氨 |
| 维生素D | ✅ 食物来源为主 | ⚠️ 皮肤可合成 | 猫皮肤合成VD能力有限 |
| 蛋白质 | ✅ 高需求 | ✅ 较低需求 | 猫为专性肉食动物，蛋白需求约为犬的2倍 |

## 四、补充剂添加决策树

```
猫自制食谱完成基础食材后 → 检查以下补充需求：

1. 牛磺酸？→ 必须补充（无论什么配方）
   计算：500 mg / 1000 kcal（熟粮）
   烹饪补偿：蒸×1.1, 煮留汤×1.2, 煮倒汤×2.5

2. 钙磷？
   ├─ 有骨 → 检查Ca:P比是否在1:0.6~1:1.3
   └─ 无骨 → 添加骨粉(肉重1-1.5%)或蛋壳粉

3. 维生素A？
   ├─ 有肝脏(≥5%) → 通常足够（注意不要过量！）
   └─ 肝脏不足 → 添加鱼肝油或VA补充剂

4. 维生素D？
   ├─ 有沙丁鱼+肝脏 → 通常足够
   └─ 缺少 → 添加VD3补充剂

5. 维生素E？→ 根据PUFA含量计算
   公式：基础6mg + (PUFA(g)-5)×0.6

6. 烟酸？→ 足量动物蛋白通常足够
   蛋白<30% → 考虑补充

7. 碘？→ 海藻粉少量(需核对碘含量) 或 鳕鱼/鲱鱼50-80g
   ⚠️ 不推荐加碘盐（钠过高，猫对钠更敏感）

8. 胆碱？→ 有蛋黄通常足够
   无蛋黄 → 考虑补充
```

## 五、安全警告

1. **牛磺酸是猫的必需营养素**，缺乏可致不可逆的视网膜退化和心肌病，熟制饮食必须补充
2. **猫不能吃狗粮**，长期食用会导致牛磺酸、精氨酸、VA、AA、烟酸等多种营养素缺乏
3. **脂溶性维生素(A/D)容易过量**，特别是VA，猫的VA中毒可致骨骼病变
4. **生蛋清含抗生物素蛋白**，长期食用可导致生物素缺乏
5. **生鱼含硫胺素酶**，可破坏维生素B1，导致硫胺素缺乏
6. **洋葱/大蒜/百合等对猫毒性极强**，使用前必须检查有毒食物清单
7. **精油对猫有毒**，猫肝脏缺乏葡糖醛酸转移酶，许多药物和精油不能正常代谢

### 6.3 猫特有补剂

| 营养素 | 补剂形式 | 常见规格 | NRC需求(猫/1000kcal) |
|--------|---------|---------|---------------------|
| **牛磺酸** | 纯粉/胶囊 | 500mg/粒 | 500mg(熟粮), 煮倒汤需×2.5 |
| **花生四烯酸(AA)** | AA补充剂 | 按产品标签 | 约50mg(生长/繁殖) |
| | 天然来源 | 蛋黄、动物脂肪、肝脏 | — |
| **EPA/DHA** | 鱼油(三酯形式) | 1000mg胶囊≈300mg EPA+DHA | 猫适量(防黄脂病) |
| | 三文鱼(天然) | 100g≈0.86g EPA+1.1g DHA | 同时提供VD/Se |

> ⚠️ 猫补充剂注意事项：
> 1. 猫体型小，剂量必须精确计算——补剂应优先选择液体/滴剂形式而非片剂
> 2. 猫对许多人类补剂成分敏感（如精油、某些草药），必须使用宠物专用产品
> 3. 维生素E与PUFA比例：生育酚(mg)/PUFAs(g) ≥ 0.6（防黄脂病）
> 4. EPA+DHA不宜过高——猫高不饱和脂肪酸饮食易致黄脂病
