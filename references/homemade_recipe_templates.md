## 三、变体差异规律分析

通过对比10个变体的数据，总结以下差异规律：

### 3.1 全食物版 vs 补充剂版差异

| 对比项 | 全食物版 | 补充剂版 |
|--------|---------|---------|
| 牛肝 | 4 oz | 5 oz（更多） |
| 葵花籽 | 3.5 oz | 2 oz（更少） |
| 牡蛎 | 3 oz | 无（用铁/锌补充剂替代） |
| 小麦胚芽油 | 20-25g | 无（用维E补充剂替代） |
| 营养酵母 | 25g | 无（用B族补充剂替代） |
| 蛋壳粉 | 13-17g | 13-15g |
| 胆碱 | 6000-7500mg（食物来源） | 4500-6000mg（补充剂） |
| 牛磺酸 | 2500mg（食物来源） | 2000-2500mg（补充剂） |
| 碘 | 海藻粉 1g | 碘补充剂 675µg |

| 维生素B族 | 营养酵母 | B50片剂 |
| 维生素E | 小麦胚芽油 | 50-100 IU 补充剂 |

| 食材/补充剂 | Baked | Gently Cooked | Raw |

| 食材 | 猫用 | 犬用 | 差异 |
|------|------|------|------|
| 牛肝 | 4 oz | 5 oz | 犬+25% |

| 牡蛎 | 3 oz | 1 oz | 猫+200% |
| 小麦胚芽油 | 25g | 30g | 犬+20% |

## 四、使用说明

### 配方生成时如何使用本模板

1. **选择主食谱**：根据用户提供的蛋白质来源，从33个主食谱中选择最匹配的
2. **选择变体维度**：
   - 宠物类型 → 犬用 adult-canine / 猫用 feline
   - 食物类型 → 全食物版（天然食材）/ 补充剂版（用补充剂替代部分食材）
   - 烹饪方式 → 轻烹（对应 SKILL 蒸/低温慢煮）/ 烘烤（对应 SKILL 蒸）
3. **按比例缩放**：根据狗的每日热量需求（MER）缩放食材用量
4. **营养验证**：用 FoodData Central 查询每种食材的营养成分，对照 NRC/AAFCO/FEDIAF 标准

### 变体差异规律的应用

当缺少某个变体的精确数据时，可根据上述差异规律推导：

- **全食物版 → 补充剂版转换**：减少牡蛎/小麦胚芽油/营养酵母，增加补充剂（铁/锌/锰/碘/B族/维E）
- **烘烤 → 轻烹转换**：油脂和胆碱减少约20-25%
- **轻烹 → 生食转换**：用量基本相同
- **猫 → 犬转换**：蔬菜量×2-4，鸡蛋×2，牛磺酸可减少（犬可自合成）
